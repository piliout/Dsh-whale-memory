## 4. 执行步骤

### Step 0 — 建代码备份（不备份数据目录）

```bash
BK="D:/AI-deepseek/dsh-onebot-qq/backups/whale-memory-20261117-2130"
mkdir -p "$BK/lib"
cd "D:/AI-deepseek/dsh-onebot-qq/plugins/whale-memory"
cp index.js "$BK/index.js"
cp lib/archive.js lib/memory.js lib/graph.js "$BK/lib/"
```
备份必须放 `plugins/` **外面**：`plugins/` 下每个子目录都会被内核当插件扫，叫 `*.bak-*` 也照样扫。放这里既不会被加载，也不会跟插件目录混。

### Step 1 — 覆盖 4 个代码文件

```bash
SRC="D:/工作区/wm-merge"
DST="D:/AI-deepseek/dsh-onebot-qq/plugins/whale-memory"
cp "$SRC/index.js"         "$DST/index.js"
cp "$SRC/lib/archive.js"   "$DST/lib/archive.js"
cp "$SRC/lib/memory.js"    "$DST/lib/memory.js"
cp "$SRC/lib/graph.js"     "$DST/lib/graph.js"
```

**不要**从 `E:/Github插件/whale-memory/` 直接拷：那个工作区是 CRLF（`git ls-files --eol` 显示 `i/lf w/crlf`），拷过去会把 4 个文件全变成 CRLF，下次 diff 又是一屏「整文件改动」。`wm-merge` 里已是 LF。

### Step 2 — 校验写入结果

```bash
cd "D:/AI-deepseek/dsh-onebot-qq/plugins/whale-memory"
sha256sum index.js lib/archive.js lib/memory.js lib/graph.js
node --check index.js && node --check lib/memory.js && node --check lib/archive.js && node --check lib/graph.js && echo "syntax ok"
# 行尾：字节数 == 去掉 \r 后的字节数，即 LF（本机 grep/awk 不认 \r，别用它们判断）
for f in index.js lib/memory.js lib/archive.js lib/graph.js; do
  a=$(wc -c < "$f"); b=$(tr -d '\r' < "$f" | wc -c)
  echo "$f $([ "$a" = "$b" ] && echo LF || echo CRLF)"
done
```

哈希必须与 §2 表一致；4 行必须全是 `LF`。

## 8. 这次到底改了什么（review 用）

7. 记忆图 `</script>` 转义（`u003c`）—— 群友说过 `</script>` 就整页白屏
8. 印象匹配去掉多余的 `extra_target_of` 包装
9. 注释纠正 `MAINT_ONLY_TOOLS` → `MAINT_ALLOWED_TOOLS`
